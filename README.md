# Next Study — маршрутизация Next.js

Учебный многостраничный сайт на Next.js и TypeScript. Практика по маршрутизации, Layout и Template.

## Запуск

Нужен Node.js 20.9 или новее.

```bash
npm install
npm run dev
```

Открыть в браузере: http://localhost:3000

Для проверки сборки:

```bash
npm run build
npm run lint
```

## Страницы

| URL | Назначение |
| --- | --- |
| `/` | Главная страница |
| `/about` | О проекте |
| `/blog` | Список статей |
| `/blog/1` | Динамическая страница статьи |
| `/blog/1/comments/5` | Вложенный комментарий |
| `/courses` | Список курсов |
| `/courses/1` | Динамическая страница курса |

Используются `Link`, `usePathname`, `useRouter` и асинхронные `params`.

В блоге реализованы `app/blog/layout.tsx` и `app/blog/template.tsx`. Для наглядной проверки сброса состояния есть дополнительный шаблон `app/blog/[id]/template.tsx`. Нажмите на счетчики, а потом перейдите с `/blog/1` на `/blog/2`: счетчик в layout сохранится, счетчик внутри шаблона статьи сбросится.

## Ответы на вопросы

**1. Как Next.js определяет URL?** По папкам внутри `app/`. Например, `app/about/page.tsx` соответствует `/about`.

**2. Layout и Template?** Layout остаётся при переходах между дочерними страницами, а template может создаваться заново и сбрасывать состояние вложенных компонентов.

**3. Как получить параметр динамического маршрута?** Создать папку `[id]` и получить `id` из `await params`.

**4. Зачем Link вместо a?** `Link` позволяет переходить внутри Next.js без полной перезагрузки страницы.

**5. Как получить параметры в клиентском компоненте?** Использовать `useParams<{ id: string }>()` из `next/navigation`.

**6. Что будет при переходе с `/blog` на `/blog/1`?** Общий `app/blog/layout.tsx` сохранится, а содержимое страницы поменяется.

**7. Как сделать вложенный маршрут?** Создать `app/blog/[id]/comments/[commentId]/page.tsx`.

**8. Почему params — Promise?** В Next.js 15 параметры передаются асинхронно. Поэтому в серверной странице используем `await params`.

## Файлы

- `app/layout.tsx` — общий макет сайта
- `app/components/NavBar.tsx` — меню с активной ссылкой и кнопкой перехода
- `app/blog/layout.tsx` — постоянный макет раздела «Блог»
- `app/blog/template.tsx` — шаблон раздела
- `app/blog/[id]/template.tsx` — сброс состояния при переходе между постами
- `app/courses/layout.tsx` — вложенный макет курсов
- `app/globals.css` — стили всего проекта

Все данные об учебных статьях и курсах находятся в `app/data.ts`. База данных не требуется.
